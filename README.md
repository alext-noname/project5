# Домашние задания

Настольное приложение для учёта домашних заданий. На вкладке «Главная» можно создавать дисциплины, менять их порядок, вести для каждой список заданий, при необходимости указывать дедлайн, отмечать выполнение, изменять и удалять задания. В настройках выбираются светлая/тёмная тема и язык интерфейса (украинский, русский или английский). Списки заданий можно экспортировать и импортировать через буфер обмена между студентами. Приложение использует собственную иконку, а установщик создаёт ярлыки в меню «Пуск» и на рабочем столе.

В Windows приложение включает поддержку DPI-aware режима для более чёткого отображения на экранах с масштабированием. Перезапустите приложение после изменения масштаба экрана.

## Требования

- Python 3.10 или новее
- Tkinter (обычно входит в установку Python)

Внешние Python-пакеты не требуются.

## Запуск

Из папки проекта выполните:

```powershell
python app.py
```

Файл с данными создаётся при первом добавлении дисциплины или задания.

Также приложение можно запустить через `run_app.bat`. Для этого требуется установленный Python 3.10+ с Tkinter.

## Установка и ярлыки через Inno Setup

1. Откройте `setup.iss` в Inno Setup 6 Compiler.
2. Выберите **Build → Compile**.
3. Установщик `installer_output\HomeworkTrackerSetup.exe` создаст ярлык в меню «Пуск». Ярлык на рабочем столе можно включить на шаге выбора дополнительных задач.

Установщик размещает приложение в профиле текущего пользователя и не устанавливает Python. На компьютере должен быть Python 3.10+ с Tkinter.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

## Настройки и обмен списками

Дедлайн необязательный. Если он указан, используйте формат `ГГГГ-ММ-ДД`, например `2026-11-25`. Тема и язык сохраняются при перезапуске.

В настройках кнопка копирования помещает все дисциплины и задания в буфер обмена в формате JSON. Вставка импортирует список, объединяя его с текущими данными: недостающие дисциплины и задания добавляются, совпадения по названию дисциплины, названию задания и дедлайну пропускаются. Существующие записи не заменяются. Буфер обмена должен содержать экспорт этого приложения.

## Разработка с AI-агентом и проверка

AI-агенту было поручено создать настольное приложение с главной вкладкой, вводом названия дисциплины и списком домашних заданий. Агент помог подготовить модели данных, локальное хранилище, интерфейс Tkinter и тесты; решения по объёму MVP и проверка кода выполнялись человеком.

Code review выявил ошибочное предположение в первоначальной загрузке данных: корневое значение JSON всегда является объектом. Добавлена проверка схемы файла; тест `test_invalid_file_shape_is_reported` проверяет, что неподдерживаемый формат приводит к понятной ошибке, а не к `AttributeError`.

Проверки включают добавление, изменение и перемещение дисциплин, защиту от повторного названия, пустой и некорректный дедлайн, добавление/изменение/удаление задания, отметку выполнения, миграцию старых записей с приоритетом, сохранение темы и языка, а также проверку импорта/экспорта и пропуска дубликатов. Тесты запускаются командой выше.

## Ограничения MVP

- Данные хранятся только в локальном JSON-файле; синхронизации и учётных записей нет.
- Уведомлений о сроках нет; дедлайн вводится вручную в формате `ГГГГ-ММ-ДД`.
- Дисциплины и задания доступны в одном пользовательском профиле на одном компьютере.
