# Howework Tracker

Настільний застосунок для обліку домашніх завдань. На вкладці «Головна» можна додавати дисципліни, додавати завдання, за потреби вказувати дедлайн, позначати виконання, редагувати та видаляти завдання. У налаштуваннях доступні світла й темна тема, а також українська або англійська мова інтерфейсу. Списки завдань можна експортувати й імпортувати через буфер обміну між студентами. Застосунок має власну іконку, а встановлювач створює ярлик на робочому столі.

# Вимоги

- Python 3.10 або новіший
- Tkinter

## Запуск

Із теки проєкту виконайте файл:

**HomeworkTrackerSetup.exe**

Програма встановиться на ваш комп'ютер.

## Тести

```powershell
python -m unittest discover -s tests -v
```

## Налаштування та обмін списками

Дедлайн необов’язковий. Якщо він зазначений, використовуйте формат `РРРР-ММ-ДД`, наприклад `2026-11-25`. Тема й мова зберігаються після перезапуску.

У налаштуваннях кнопка копіювання розміщує всі дисципліни та завдання в буфер обміну у форматі JSON. Вставлення імпортує список, об’єднуючи його з поточними даними.

## Розробка з AI-агентом і перевірка

AI-агенту було доручено створити настільний застосунок із головною вкладкою, введенням назви дисципліни та списком домашніх завдань. Агент допоміг підготувати моделі даних, локальне сховище, інтерфейс Tkinter і тести. Рішення щодо обсягу MVP і перевірку коду виконував я.

Code review виявив помилкове припущення в початковому завантаженні даних: кореневе значення JSON завжди є об’єктом. Додано перевірку схеми файлу.

Перевірки охоплюють додавання, зміну та переміщення дисциплін, захист від повторних назв, некоректний дедлайн, додавання/зміну/видалення завдання, позначення виконання, збереження теми й мови, а також перевірку імпорту/експорту й пропуску дублікатів. Тести запускаються наведеною вище командою.

## Обмеження MVP

- Дані зберігаються лише в локальному JSON-файлі; синхронізації й облікових записів немає.
- Сповіщень про строки немає; дедлайн вводиться вручну у форматі `РРРР-ММ-ДД`.
- Дисципліни й завдання доступні в одному профілі користувача на одному комп’ютері.
